# ArcScore brand

## The idea
An athlete's value is a ball in flight. **Score** is where it is now. **Arc** is where it's going.
The whole identity comes from that one image: a single arc and a single ball.

## Principles
1. **Neutral bodies, one signal.** Paper and ink do the work. Signal orange appears only on the ball: in the mark, on the score gauge, and at "now" on a chart. Never on buttons, links or backgrounds.
2. **The product is the hero.** Marketing shows the real interface, not illustrations of it.
3. **Two numbers, nothing else to learn.** Every screen leads with Score and Arc. Anything else is supporting detail.
4. **Explain, don't decorate.** Each number can be traced to the signals behind it.
5. **Quiet motion.** Things draw on once and settle. Nothing loops for attention except the cursor-driven bits.

## Mark
A half arc in ink with the ball at its landing point in Signal orange. The wordmark "arcscore" is set lowercase in Geist Semibold with tight tracking. The score gauge in the product is the same mark, drawn to scale.

## Color
| Token | Hex | Use |
|---|---|---|
| Paper | `#F6F5F1` | Page background |
| Surface | `#FFFFFF` | Cards, sheets |
| Sunken | `#EFEEE9` | Wells, tracks, hover |
| Line | `#E5E3DC` | Hairlines |
| Ink | `#111110` | Text, primary buttons, data marks |
| Ink 2 / 3 / 4 | `#4A4944` / `#85837C` / `#B3B0A7` | Secondary text, labels, disabled |
| **Signal** | `#FF5A1F` | The ball. Only the ball. |
| Good / Warn / Bad | `#1F7A4D` / `#A86A00` / `#C03A2B` | Status only, always with an icon and a label |

## Type
Geist for everything, Geist Mono for chart axes. Display sizes use −0.045em tracking and a 0.95 line height. Numbers are tabular.

## Data
Charts are single-hue ink: history is solid, projection is dashed, and "now" is the orange ball. Status colors never stand in for series colors.
